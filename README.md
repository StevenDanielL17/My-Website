# Dan's World - 3D Portfolio

A stunning 3D portfolio website built with Next.js, React Three Fiber, and GSAP animations.

## 🚀 Features

- **3D Interactive Elements** - Built with React Three Fiber and Three.js
- **Smooth Animations** - GSAP and Anime.js for premium transitions
- **Scroll-based Interactions** - Lenis smooth scroll integration
- **Responsive Design** - Tailwind CSS for modern styling
- **Performance Optimized** - Next.js 14 with App Router

## 🛠️ Tech Stack

- **Framework**: Next.js 14.2
- **3D Graphics**: React Three Fiber, Three.js, Drei
- **Animation**: GSAP, Anime.js
- **Styling**: Tailwind CSS, Sass
- **State Management**: Zustand
- **Smooth Scroll**: Lenis

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Deployment

### Deploy to Vercel (Recommended)

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "Ready for deployment"
   git push origin main
   ```

2. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Import your GitHub repository
   - Vercel will auto-detect Next.js settings
   - Click "Deploy"

3. **Your site will be live at**: `https://your-project.vercel.app`

### Environment Variables

This project currently doesn't require environment variables. If you add any API keys or secrets in the future, add them in:
- Vercel Dashboard → Your Project → Settings → Environment Variables
